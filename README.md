# STUDENT-ENROLLMENT-DASHBOARD
This sounds like an Educational Institution Student Enrollment Analysis Project. The project focuses on analyzing student admissions and enrolment details across different branches, courses, fee structures, and native locations. This dashboard helps to identify the total number of students that enrolled in each courses , branches and fees paid. 
# Features
1.  Total Students
2.  Total Instructors
3.  Total fees
4.  Total fees collected
5.  Balance fees
6.  Number of students where courses completd
7.  Number of ongoing students
8.  Branch wise student count
9.  Enrollment month trends
10.  Couse wise revenue
11.  course wise enrollment

# Key insights 

1.Significant outstanding fee balance.

2.Ongoing students slightly outnumber completed students.

3.ERP is the leading revenue-generating course category.

4.Abu Dhabi and Al Ain lead branch-wise enrolment.

5.Course enrolment is concentrated in a few popular courses.

6.Student enrolment comes from diverse nationalities.

7.Different learning modes attract students.

# Recommendations

1.Introduce automated payment reminders.

2.Monitor student progress regularly.

3.Expand course batches where demand supports it.Introduce advanced-level courses in ERP and Analytics.

4.Maintain adequate instructors and facilities in these branches.

5.Conduct regular market research to understand student preferences.

6.Develop marketing campaigns targeting different nationalities.

7.Continue providing multiple learning modes.Collect student feedback on each mode.
